# SA · Portfólio público

Site estático. Página inicial: `index.html`.

Para GitHub Pages, envie somente o conteúdo desta pasta ao repositório e selecione a pasta raiz da branch como origem de publicação. Mantenha o arquivo `.nojekyll`.

Não requer servidor de aplicação, API ou instalação de dependências. Fotografias, imagens financeiras e vídeos presentes são locais. Links de mapas e anúncios requerem internet.

Não copie pastas de revisão, documentos ou arquivos de trabalho para o repositório.
